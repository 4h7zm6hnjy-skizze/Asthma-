ASTHMA-AMPEL DIREKT UNTER PATIENTENPROFIL – iPHONE

Nur eine Datei muss ersetzt werden: ampel320.js

1. Öffne mit deinem iPhone Safari und https://github.com/4h7zm6hnjy-skizze/Asthma-
2. Stelle sicher, dass du bei GitHub angemeldet bist.
3. Tippe auf „Add file“ und dann „Upload files“.
   Ggf. in Safari über das Menü aA / Website-Einstellungen die Desktop-Website anfordern.
4. Wähle aus der Dateien-App nur die heruntergeladene Datei ampel320.js aus.
5. Bestätige „Commit changes“ (Änderungen speichern). Falls GitHub das Ersetzen
   einer bestehenden Datei auf diesem Weg nicht erlaubt: Datei auf GitHub öffnen,
   Stift-Symbol / „Edit this file“ wählen und den Inhalt ersetzen.
6. Beende die Asthma-App vollständig und öffne sie erneut bei bestehender
   Internetverbindung. Du kannst alternativ im gleichen Safari-Profil neu laden.

Das In-App-Update meldet weiterhin Version 3.2.0, weil ausschließlich
 die Position geändert wird. Kein Löschen der App, keine Datenbereinigung!
Die Änderung verschiebt nur das vorhandene Bedienelement unter „Patientenprofil“.
Gespeicherte Einträge, Notizen, Auswertungen und die Datenbank bleiben unverändert.
