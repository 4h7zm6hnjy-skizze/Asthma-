# Asthma · Version 1.1.0

Statische Offline-fähige Webapp mit GdB-abhängiger Wissenssuche und 29 zusätzlichen Leistungen / Antragswegen.

## Neue Funktionen

- Suche und Filter für Hilfsmittel, Physio, Lungensport, Schulungen, Reha, Arbeitsplatz, Schwerbehindertenrecht und Pflege.
- 29 Einträge mit direktem Link zur offiziell belegten Stelle (teils Onlineantrag, teils Formularpaket oder Fachinformation).
- Selbst ausfüllbare Mustervorlagen, Copy-to-Clipboard und Drucken/als PDF sichern.
- Verordnungen nur über behandelnde Arztpraxis: die App erzeugt *kein* Rezept und sendet *keine* Anträge automatisch.
- Eingaben für Mustervorlagen werden nicht dauerhaft gespeichert. Bestehende Merkliste und Profilauswahl bleiben erhalten.
- Version 1.1.0 und neue Dateien im Cache.

## GitHub Pages

ZIP **entpacken** und sämtliche Dateien in die **Wurzel** des Repositories laden. Datei `index.html` und `version.json` müssen nebeneinander liegen. GitHub Pages: main / root.

## Grenzen

Kein ärztlicher Behandlungsplan, keine Leistungszusage, keine automatisierte Antragseinreichung. Ob ein GKV-, DRV-, BA- oder Pflegeanspruch besteht, prüfen zuständige Stellen individuell. Medizinische und rechtliche Sachverhalte können sich ändern; amtliche Quelle vor Antragstellung prüfen.
