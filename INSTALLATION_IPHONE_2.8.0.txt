ASTHMA 2.8.0 PROFESSIONAL – iPhone-Installation

1. In der alten WebApp mit deinem bisherigen Passwort anmelden und unter Einstellungen eine vollständige .asthma17-Datensicherung erzeugen. In „Dateien“ speichern; Backup-Passwort sichern.
2. ZIP im iPhone unter „Dateien“ antippen und entpacken.
3. Auf https://github.com/4h7zm6hnjy-skizze/Asthma- gehen.
4. Code -> Add file -> Upload files. ALLE Dateien aus dem entpackten Ordner auswählen; NICHT die ZIP und NICHT den übergeordneten Ordner hochladen. Neue und alte Dateien müssen direkt neben index.html liegen.
5. Commit directly to main -> Commit changes. GitHub kann etwas Zeit brauchen, bis Pages aktualisiert ist.
6. Bestehende Asthma-WebApp auf dem iPhone wie bisher öffnen und mit deinem bisherigen Passwort anmelden. NICHT löschen, keine Website-Daten löschen, kein neues leeres Profil erstellen.
7. Neue Startseite, Tages-Eintrag, Verlauf, Profil, Dokumentensuche und Backup-Prüfung kontrollieren.
8. Beim fehlenden Update die bestehende App schließen, wieder öffnen und in den Einstellungen „Nach Updates suchen“. Kein Löschen von Safari-Speichern.

WICHTIG: Eine fehlende alte Gesundheitsakte kann an getrennter Safari- und Home-Bildschirm-App-Speicherung liegen. Sicherung wiederherstellen nur aus einer selbst geprüften .asthma17 und mit klarer Bestätigung; nie blind überschreiben.

Hinweis: Das Paket ist eine vollständige WebApp, kein Mac-Programm. Auf echtem iPhone wurde kein vollständiger Ende-zu-Ende-Test durchgeführt.
