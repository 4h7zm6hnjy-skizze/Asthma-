# Neues Asthma-Design 2.6.0

Farben: tiefes Dunkelblau / Türkis / Mint / Weiß. Die Original-Designreferenz stammt aus den im Chat freigegebenen Entwürfen. `design26.css` gestaltet die bestehenden Seiten; `design26.js` setzt die neue Übersicht um und liest die Daten ausschließlich über `ASTHMA_SECURITY.list`. Keine neue Datenbank, keine Datenspiegelung. Diagrammmodule unverändert, nur in neue Karten verschoben.

Die Ringdiagramme zeigen FEV₁ und FVC nur aus gespeicherten Untersuchungen, nicht aus unbestätigten Eingabefeldern. Eine klinische Zustandsbewertung wird nicht allein aus den Lungenwerten abgeleitet.

Testvorschauen sind mit **Testdaten**, nicht mit dem persönlichen iPhone-Tresor, aufgenommen.
